Font family

Single sans-serif family. System-first stack for zero-network rendering.

SF Pro Display, -apple-system, BlinkMacSystemFont, sans-serif

Weights

Four weight stops. Body copy defaults to regular; headings default to whatever the tag maps to unless overridden.

--font-weight-regular 400

--font-weight-medium 500

Medium — SF Pro Display

--font-weight-bold 700

Bold — SF Pro Display
