# Editing the website copy — a quick guide

Hey Sherri,

You can now edit the wording on your landing page yourself. Here's everything you need.

## How it works

1. You log in to **Pages CMS** with your GitHub account
2. You see a clean form with every section of the website laid out as labelled fields
3. You edit the text, click save
4. **Changes go live within about a minute** — no need to email me

That's it. No code, no scary technical stuff.

## First-time setup (5 minutes, one time only)

1. **Create a GitHub account** (free) at [github.com](https://github.com) if you don't have one. Use the email address you'd like associated with the site edits.
2. Send Clark your GitHub username. He'll add you as an editor on the website repo.
3. Once you're added, go to **[app.pagescms.org](https://app.pagescms.org)** and sign in with GitHub. Authorise it.
4. Select the **hypefoundry / clients** repo from the list. You'll see "The Guidance Co. — Landing page" appear.
5. Click it. You're in.

## What you can edit

Every visible piece of text on the homepage, grouped by section:

- **Top bar:** phone number
- **Main navigation:** the five link labels and the Contact button
- **Hero:** headline, sub copy, both button labels
- **Why work with us:** section heading + the four cards
- **Who we work with:** section heading + the six audience rows
- **Services:** section heading + the six service cards
- **Founder message:** kicker, the quote itself, your name + credentials
- **Capability statement card:** eyebrow, heading, body, button label
- **Request support:** heading + the two referral cards
- **We're here to help:** heading + the two contact cards (phone, email, hours)
- **FAQ:** heading + all seven questions and answers
- **Accreditations:** heading above the logo row
- **Footer:** copyright + credentials line

## What's locked (design team handles these)

To protect the layout, the CMS won't let you:

- **Add or remove sections** — no extra cards, no extra FAQs, etc. If you need a fifth Why card or an eighth FAQ, ping Clark.
- **Change images** — the wordmark, asterisk, photos, accreditation logos all stay put.
- **Change links** — the phone number text + the actual dial-link update together automatically; same for the email. Other links (Privacy, Terms, social) are locked.
- **Change the design** — no colours, fonts, spacing.

If you find yourself wanting to do any of those, message Clark and we'll handle it.

## Character limits

Each field has a quiet character limit so a long paste can't break the design. You'll see the count in the editor. If you hit it, you'll need to trim — the layout was built for the current word count, so going much longer would make text overflow or wrap weirdly.

If a field genuinely needs to be longer, message Clark — we'll either rework the design or raise the limit.

## After you save

- **Wait about 60 seconds.** Behind the scenes the change has to commit, GitHub Pages has to rebuild, and the CDN cache has to clear.
- **Hard-refresh the live site.** On Mac: ⇧⌘R. On Windows: Ctrl+F5. A normal refresh might serve a cached version.
- **If something looks wrong**, message Clark immediately. Every change is stored in version history so we can roll back in 30 seconds.

## Quick checklist before publishing a change

- Read the new copy out loud
- Check the character limit indicator isn't red
- Save → wait 60 seconds → hard-refresh
- Visit the page on your phone too (you'd be surprised what wraps differently on mobile)

That's it. Welcome to having direct access to your own website.
